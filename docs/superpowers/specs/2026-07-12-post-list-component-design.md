# 게시글 목록 컴포넌트 통합 설계

## 목표

홈 게시판 목록과 카테고리 게시글 목록의 중복 렌더링을 `PostList.svelte`로 통합한다.

## 범위

- 공통 목록 UI: 제목 링크, 댓글 수, 추천 점수, 말줄임, 행 레이아웃.
- 홈 전용 UI: 게시판 제목과 compact 높이는 `HomeBoard.svelte`가 유지한다.
- 카테고리 전용 UI: 페이지 헤더, 글쓰기 버튼, 빈 상태, 페이지네이션은 `[category]/+page.svelte`가 유지한다.

## 메타 표시

`PostList`의 post 타입에는 `viewCount`를 남긴다. 나중에 조회수를 표시할 수 있게 하기 위함이다.

현재 화면에는 조회수를 표시하지 않고 `💬댓글수 👍점수`만 표시한다.

## 하지 않을 것

- 큰 `BoardPage` 컴포넌트로 홈과 카테고리 페이지 전체를 합치지 않는다.
- 조회수 아이콘은 이번 변경에서 표시하지 않는다.
